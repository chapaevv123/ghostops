# Data persistence

**Backup and recovery:** Open **Integrity & Export**, run the check, then download **Export portable package**. Keep the `.ghostops-investigation.json` outside the browser profile. In a clean profile at the same or another origin, use **Import package or files** and select that package. The importer verifies schema, hashes, offsets, and deterministic replay before writing it. Check the restored title, source records, notes, and integrity result. Clearing site data or changing origin without a package can make local investigations unavailable. If cancellation races with a completed IndexedDB transaction, inspect the investigation list before retrying.

Saved investigations use IndexedDB under the page's browser origin. Metadata and payload are written in one transaction. The storage schema is versioned; a version-1 payload can be checked and migrated on open. Original source text is stored in the payload and re-ingested on open. Source and payload SHA-256 values detect mismatches against saved values. A failed check prevents a corrupted investigation from opening as if it were valid.

The browser controls quota and eviction. `QuotaExceededError` is reported to the user; there is no guarantee that all browsers will retain IndexedDB indefinitely. Private browsing, clearing site data, losing the profile, changing device or browser, or changing the hosting origin can remove or hide investigations. A static deployment at a different domain starts with separate storage. A portable package is the backup and transfer mechanism; export one before clearing data or moving environments.

Interrupted writes rely on IndexedDB transaction atomicity. The application does not claim server-grade durability, off-device backup, cross-device sync, or an independently protected audit trail. The local action history is editable by someone with access to the browser profile or exported package.

When files are imported from the Investigations screen, GhostOps validates them in a Worker before the first IndexedDB write. Rejected files do not leave an empty workspace. Imported evidence is capped at 100,000 records per investigation. Cancellation terminates the Worker; if a save has already committed before cancellation, the completed investigation can still appear in the list. Export a package before changing the deployment domain, because browser storage is scoped to the exact origin.
